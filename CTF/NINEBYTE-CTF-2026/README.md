# NINEBYTE CTF 2026

I participated in NINEBYTE CTF 2026, a cybersecurity competition focused on practical problem-solving across areas such as cryptography, digital forensics, and steganography.

The competition provided an opportunity to work through technical challenges involving damaged files, hidden information, pattern recognition, data extraction, and multi-stage puzzle solving. This repository contains selected write-ups from the challenges I completed, along with a copy of my participation certificate.

## Challenge Areas

- Cryptography
- Digital Forensics
- Steganography
- File Analysis
- Logical and Pattern-Based Problem Solving

## Key Learning Outcomes

Through these challenges, I gained further practical experience in:

- examining unusual and corrupted files;
